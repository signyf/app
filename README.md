# 天气小挂件

一个放在桌面上的无边框小窗。自己搜索地点（城市或小区都可以），查看当前气温、湿度、紫外线，以及一句简短的穿衣提示；同时显示今天的新历、农历、黄历宜忌，还有法定节假日和传统农历节日。

这一版不读取设备定位，也不需要任何 API key。

## 这一版包含

- 无边框小窗，拖动窗口即可挪位置，下次打开还在原地
- 搜索并点选地点，名称按地理编码结果展示；地点保存在本机
- 当前气温、湿度、紫外线，以及由气温和天气状况得出的穿衣提示
- 新历与农历日期
- 当天黄历宜 / 忌，以及法定节假日、传统农历节日提醒（调休上班会标明）
- 界面为中文
- 最近一次成功的天气会留在本地；暂时拉不到新数据时继续显示上次结果，并标明这是上次数据

## 在 Windows 上安装和运行

需要 [Node.js](https://nodejs.org/) 20 或更高版本。

```bash
npm install
npm start
```

拖动窗口任意空白处可以移动。点「换地点」，输入城市或小区（例如 `天通苑`、`望京花园 朝阳区`），再点一条结果。右上角「×」关闭挂件。

地点和窗口位置写在应用数据目录的 `widget-state.json` 里，重启后会读回来。

## 构建

在 Windows 上执行：

```bash
npm run dist
```

会先打包界面脚本，再用 electron-builder 生成一个免安装的 Windows 可执行文件 `release/tianqi-widget-1.0.0-portable.exe`。双击即可运行，不需要再装 Node.js。这个文件没有代码签名，图标用的是 Electron 默认图标。在 Windows 上直接执行即可；在 Linux 上交叉编译需要 Wine。

## 测试

逻辑测试不依赖窗口，在本机执行：

```bash
npm test
```

覆盖三块：地理编码结果如何整理成地点名称、穿衣提示、以及固定日期上的农历、宜忌和节日。界面本身需要在有图形环境的系统里用 `npm start` 看。

## 数据来源

- 天气： [Open-Meteo](https://open-meteo.com/)（按经纬度取气温、湿度、天气现象和紫外线）
- 地点搜索： [Nominatim](https://nominatim.org/) / © OpenStreetMap 贡献者
- 农历、黄历宜忌、传统节日和法定节假日： [lunar-javascript](https://github.com/6tail/lunar-javascript)

## 已知限制

- 小区能不能搜到，取决于 OpenStreetMap 有没有收录这个名字。有的小区只能对到同名公交站或道路，坐标大致还在那一片，足够看天气，但不是门牌级精度。重名时请看结果里的区县再选。
- 搜索一次对应一次 Nominatim 请求。请不要连续猛点，公开服务有频率限制。
- 法定节假日使用 lunar-javascript 自带年表。超出年表的年份，仍会显示传统农历节日，但当年的放假和调休可能缺失。
- 黄历宜忌来自该库的传统历法数据，只作日常参考。
- 天气服务短时不可用时，会显示上次成功的读数，并写明「天气获取失败 · 上次数据」。换了一个新地点又拉失败时，不会拿上一个地点的数据来充数。
- 没有逐小时预报、空气质量和自动定位。
